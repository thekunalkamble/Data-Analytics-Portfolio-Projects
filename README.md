## 2️⃣ Airline Database Analysis (SQL)

### Overview

Performed SQL analysis on airline operational datasets to uncover insights related to passenger trends, booking performance, flight occupancy, and route profitability.

### Concepts Used

- CTEs
- Window Functions
- Joins
- Ranking
- Aggregations
- Subqueries

### KPIs

- Occupancy Rate
- Route Profitability
- Delayed Flights
- Revenue Leakage
- Passenger Count

Identified underperforming routes contributing to approximately 15% revenue leakage.
